# Phase 1 — Prompts Used

## Test Set A — 5 prompts de dificultad media

### A1_math
```
Calculate the sum of all prime numbers between 1 and 100. Show your work briefly.
```

### A2_logic
```
If all roses are flowers and some flowers fade quickly, can we conclude that some roses fade quickly? Explain your reasoning.
```

### A3_coding
```
Write a Python function to check if a string is a palindrome, ignoring case and non-alphanumeric chars. Include 2 tests.
```

### A4_knowledge
```
Explain the difference between TCP and UDP. Give 2 example protocols for each.
```

### A5_creative
```
Write a 4-line poem about artificial intelligence in iambic pentameter.
```
